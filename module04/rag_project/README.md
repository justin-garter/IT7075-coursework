# RAG for Defense Contractor Compliance (DFARS, CMMC, ITAR)

IT7075C Applied AI for Cybersecurity, Mini Project 3. A retrieval-augmented generation system built from scratch (no LangChain) over five excerpts of U.S. federal regulations that govern aerospace and defense manufacturers: DFARS 252.204-7012/7019/7020, the CMMC program rule (32 CFR 170), and ITAR (22 CFR 120 and 122). Documents are chunked, embedded locally with `all-MiniLM-L6-v2`, stored in ChromaDB with cosine distance, and retrieved with a distance threshold so off-topic questions get no context. Answers are generated by `mistral:7b` through a loopback-only Ollama server. An 8-question gold set (6 answerable, 2 not) scores each configuration by answers found and refusals held while chunk size, k, and the threshold are varied one at a time.

| File | Contents |
|---|---|
| `rag_notebook.ipynb` | Practice pipeline (Parts 1 to 5) and the compliance RAG (Part 6), saved with outputs |
| `my_kb/` | The five regulation excerpts and `SOURCES.md` |
| `goldset.json` | The eight evaluation questions |
| `results.csv` | One row per configuration tested |
| `figure.png` | Answers found and refusals held for each setting |
| `course_kb/`, `baseline_goldset.json` | Course documents and questions used in Parts 1 to 5 |

Run locally: `pip install sentence-transformers chromadb pandas matplotlib`, start Ollama with `mistral:7b` pulled, then run the notebook top to bottom from this folder.
